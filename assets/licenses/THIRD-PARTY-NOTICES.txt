AirPlay 2 Speaker for Kiosk Satellite: third-party notices
==========================================================

The plugin's own code (plugin.jar) and build scripts are under the MIT license in
LICENSE. The package also contains two programs built from other people's work:

  native/armeabi-v7a/libshairport.so   shairport-sync, statically linked with
                                       OpenSSL, libsodium, libgcrypt, libgpg-error,
                                       libplist, libconfig, popt and FFmpeg
  native/armeabi-v7a/libnqptp.so       NQPTP

Each is a separate program, started as its own process. Their licences are below
and the full texts are in this folder (assets/licenses/ in the package).


Source code
-----------

Every release at
  https://github.com/KieranWaugh/kiosk-satellite-plugin-airplay2/releases
has, attached next to the plugin ZIP, the exact source of every component (the
pinned upstream tarballs listed below) and native-sources.tar.gz, which holds the
build script (native/build.sh) and every patch and added file. The release's tag
in the repository holds the same files. native/build.sh downloads each tarball,
checks its SHA-256, applies the patches and builds both programs with the Android
NDK, so you can rebuild them, or relink with a modified version of any of the
LGPL libraries, and install the result with Plugin Manager > Developer Tools >
Install from ZIP. This offer of source is also good for three years from each
release, from the author through the repository's issues.
